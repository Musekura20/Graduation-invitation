Graduation invitation website

1. Keep index.html and style.css in the same folder.
2. Open index.html in a browser to preview the invitation.
3. The Saint Famille link opens Google Maps directions to Saint Famille, Kigali, Rwanda.
4. To publish it online, upload these files to GitHub Pages, Netlify, or Cloudflare Pages.

Note: The map link uses the place name as a destination search. Confirm the exact venue/pin before sharing the public invitation.
